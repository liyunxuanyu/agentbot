# 文件读写

对应工具：`read_file` / `write_file` / `edit_file`。

## 什么时候用

- 改代码或文档之前，先用 `read_file` 看清要改的那一段。
- 新建文件用 `write_file`；**修改已有文件优先用 `edit_file`**（只替换指定片段，
  不会把文件的其它部分重写一遍）。
- 需要知道目录里有什么时用 `list_dir`（见 search-basics），不要靠猜路径。

## 工作顺序

1. **先读**：`read_file(path)`。读取结果会截断（默认 64KB），大文件先定位再读。
2. **再改**：`edit_file(path, oldText, newText)`。`oldText` 必须在文件里
   **唯一出现**；不自知时多带几行上下文，别只给一个 `}`。
3. **改完自检**：重新 `read_file` 受影响的那一段，确认替换位置正确、
   没有破坏相邻代码。需要时跑一次类型检查或相关测试。

## 常见错误

- **只读半截就改**：文件被截断时，后面的内容不在你看到的结果里；用 grep 定位
  后再读目标区间。
- **`edit_file` 的 oldText 不唯一**：同一段代码出现两次时，替换会失败或改错位置。
- **整文件重写做小修改**：容易丢注释与格式；已有文件优先用 `edit_file`。
- **写文件时编造路径**：不确定目录结构时先 `list_dir`。

## 边界

- 所有路径必须在工作区内。`..` 与符号链接逃逸会被拒绝，**不要试图绕过**。
- 写/编辑需要用户批准（计划模式下工具直接不可用）。被拒绝时说明需要什么，
  不要重复同一个调用。
- 二进制文件不要用 `read_file` 读，也不要用 `write_file` 写。
