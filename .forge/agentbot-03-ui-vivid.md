# AgentBot 视觉设计系统 · vivid

> 变体 `vivid`，令牌：`agentbot-tokens-vivid.css`。输入：`agentbot-ui-research-real.md`、`agentbot-02-ux.md`、`agentbot-01-prd.md`。

## 1. 方向陈述

Bot 是同事，不是进程。浅灰白底、纯白圆角卡片、16px 气泡、有名字有颜色的头像，界面要像一群人真的在群里干活。品牌青蓝只管「动作」，Bot 身份色只管「是谁」，语义色只管「发生了什么」——三者分区使用，永不混用。动效的作用是安心感：让人看见它还在动。**关键词**：热闹 / 有人味 / 有回弹

## 4. 圆角与阴影

### 4.1 圆角刻度（最小 4px，全站无直角）

| 令牌 | 值 | 用途 |
|---|---|---|
| `--radius-xs` / `--radius-sm` / `--radius-md` | 4 / 8 / 10px | 进度条、气泡尾角 / 头像方牌、事件行 / **按钮**、折叠块、列表行、导航项 |
| `--radius-lg` / `--radius-xl` | 12 / 14px | 工具调用块 / **卡片**、权限卡、弹层内块 |
| `--radius-2xl` / `--radius-3xl` | 16 / 20px | **消息气泡** / 弹层抽屉 |
| `--radius-pill` / `--radius-full` | 24px / 999px | **输入框（胶囊）** / 状态点、未读数字、圆形头像 |

头像两种形态：圆形 `50%`（默认）或 8px 方牌（像素风 Bot）。唯一允许的直线是 1px 分隔线。

### 4.2 连续消息气泡圆角规则

同一发言人连续消息，尾部角落缩到 4px，其余保持 16px，**缺口朝头像方向**：

| 位置 | TL / TR / BR / BL | 位置 | TL / TR / BR / BL |
|---|---|---|---|
| Bot 单条 = 组首 | 16 / 16 / 16 / **4** | Bot 组末 | **4** / 16 / 16 / 16 |
| Bot 组中 | **4** / 16 / 16 / **4** | 用户（右对齐） | 16 / 16 / **4** / 16 |

配套三条：连续消息垂直 gap 从 12px 降到 4px；组首之后不重复头像与名字；悬停才显示时间。三条一起作用，5 条连发看起来是「一段话」而不是「五条消息」。

### 4.3 阴影三级

| 令牌 | 值 | 用途 |
|---|---|---|
| `--shadow-card` | `0 1px 2px rgba(22,32,43,.05), 0 2px 8px rgba(22,32,43,.04)` | 卡片、气泡、输入框 |
| `--shadow-raise` | `0 6px 16px rgba(22,32,43,.08)` | 悬停卡片、权限卡、吸顶 Turn 头 |
| `--shadow-overlay` | `0 16px 40px rgba(22,32,43,.12)` | 弹层、下拉、@ 选择器 |

阴影用墨蓝 `rgba(22,32,43)` 而非纯黑——浅灰白底上不显脏；焦点环 `0 0 0 3px rgba(12,122,143,.28)`。

## 5. 间距与栅格

刻度 **4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48 / 64**（`--space-1`…`--space-10`）。用途：4 连续气泡 gap、图标与文字；8 chip 内；12 列表行内、气泡组间；16 小卡内边距；20 **卡片网格 gap**、事件缩进；24 卡片内边距、区块间距；32 页面左右内边距；40 区块上下留白；48 空态上下留白；64 首屏 / 向导留白。栅格：应用壳 `240 导航 | 弹性主区 | 320 右面板`（右面板仅 `/chat`、`/assignments/:id`）；消息流最大 860 居中、气泡最大 660（约 40 个中文字/行）；Bot 网格 ≥1280 三列、1024–1280 两列、<1024 一列，列 min 320、gap 20。断点 640 / 768 / 1024 / 1280 / 1440。

## 6. 动效系统

| 令牌 | 值 | 令牌 | 值 |
|---|---|---|---|
| `--ease-spring` | `cubic-bezier(.34,1.56,.64,1)` | `--duration-press` / `--duration-hover` | 120 / 160ms |
| `--ease-out` / `--ease-in-out` | `cubic-bezier(.22,.61,.36,1)` / `cubic-bezier(.4,0,.2,1)` | `--duration-fast` / `--duration-base` | 200 / 240ms |
| `--stagger-step` | 40ms | `--duration-slow` / `--duration-page` | 280 / 360ms |

| # | 动效 | 规格 |
|---|---|---|
| 1 | 区块进入 | opacity 0→1 + translateY(10px)→0，240ms spring；同级 stagger 40ms（`--i * 40ms`），超 5 项不再延迟 |
| 2 | 气泡出现 | opacity + translateY(8px) + scale(.97)→1，200ms spring，origin `bottom left`；**连续消息只做 opacity 120ms** |
| 3 | 流式光标 | 2px × 1.05em，r1，色 = Bot ink，1s `steps(1)` 闪；段末移除；非流式运行时完全不出现 |
| 4 | 状态变化 | 颜色 160ms 交叉 + 六态各自动效（见 §2.5），working 的扫光是唯一的长循环 |
| 5 | 按钮按压 | hover translateY(-1px) 160ms；active scale(.96) 120ms spring；释放 200ms 回弹 |
| 6 | 弹层进出 | 进 scale(.96)+translateY(6px)→1，200ms spring，遮罩 160ms；出 scale(.98)，140ms ease-out |

**动效预算**：同屏同时运动元素 ≤3。多 Bot 并行时只有「展开中的 Turn」有扫光与光标，其余活动行只保留状态点呼吸。**`prefers-reduced-motion: reduce`**：位移与缩放全部归零（`transform: none`），时长降至 1ms，无限循环改静态（状态靠颜色 + 图标 + 文字），光标不闪改为常显竖条，折叠块不自动展开，stagger 取消。

## 8. 关键页面视觉规格

### 8.1 `/bots`（一屏区分多个 Bot）
汇总条：4 组数字（Bot 数 / 运行时数 / 执行中 / 待批），数字 26px/800 tabular，标签 12px muted，组间 32。筛选 chips 用 secondary 型，选中变 `--color-primary-soft` + `--color-primary-ink`。网格 3 列 gap 20，1440×900 一屏 6 张。**扫读路径**：身份条（谁）→ 40 头像 + 名称（谁）→ 状态点 + 文字（在干嘛）→ 运行时胶囊（在哪跑）→ 等宽路径（在哪改）。身份条是网格里唯一的强色块，20 个 Bot 也能按颜色一眼定位。骨架卡与真卡同尺寸（320×200），加载不跳动。

### 8.2 `/chat/:channelId`（群聊多 Bot 不刷屏）
流宽 860 居中、气泡 660；Turn 间 20px，Turn 内事件 8px。
- **身份三重锚**：Turn 头（吸顶，3px 身份轨 + 头像 + 名字）、气泡 3px 左轨、头像右下状态角标。滚到任何位置都能回答「这是谁」，不用往回翻。
- **单展开**：同时只有一个 Turn 展开流式；其余运行中的 Bot 折叠为 40px 活动行（20 头像 + `正在运行 npm test · 12s` + 2px Bot 色进度条），点击接管。
- **轮次栅栏**：轮末插一条极轻 `— 本轮结束 · ●●● · 4,120 token —`，三个点就是参与者身份色；**输入区** sticky 底部，权限卡出现时贴输入框上方，锁定时胶囊变 `#EEF2F5` 底 + `等待你批准` 占位。

### 8.3 `/usage`
不用密集表格：行高 56，Bot 头像 + 名称 + 运行时 chip，右侧 4 列等宽 tabular 右对齐，行尾 6px 占比条用该 Bot 身份色。表头 12px muted、正常大小写（不用全大写）。合计行加 1px 上边线 + `--color-surface-2` 底。窄屏（<1024）每行转卡片：名称一行、3 个数字一行、占比条占满宽。

## 9. 与 UX 五原则的对应

| 原则 | 视觉落点 |
|---|---|
| 1 Bot 是主角，运行时是属性 | 身份色 + 头像贯穿 5 处（列表 / 卡片 / 气泡 / 成员 / 用量）；运行时永远是 22px 灰胶囊，无颜色 |
| 2 能力可见而非缺失 | 能力徽标三态都带文字；未声明的事件**不渲染任何占位**，不留灰块 |
| 3 治理在主流程内 | 权限卡片在流内 sticky，4px 琥珀左轨 + raise 阴影，是流里唯一「浮起来」的卡 |
| 4 一次只展开一层 | 折叠块压到 32px 一行；气泡内不出现参数；同一时刻只允许一个 Turn 展开 |
| 5 缺席要可解释 | 活动行、系统块、未发言原因都用 muted 文字直说，不用空白或省略号 |

## 10. 局限与风险

1. **18 色同屏**（8 身份 + 6 状态 + 4 语义）靠「形态分区」压住：身份色只做 ≤32px 块与 ≤3px 轨，语义色只做整卡底。新增组件若打破这条，界面会立刻变吵。
2. **回弹缓动有晕眩风险**：`--ease-spring` 只用于出现与按压，绝不用于滚动、列表重排、连续消息；`prefers-reduced-motion` 下完全失效——有意为之，不做折中版本。
3. **暖色挤在一起**：bot-5 赭橙、warning 琥珀、danger 红在色相环 8°–40° 区间内，靠尺度区分（身份 = 32px 方块；语义 = 整卡底 + 图标 + 文字），色弱用户依赖名字文字。
4. **最近的一对是 bot-5 赭橙（H17）与 bot-7 芥金（H43）**，仅差 26°，饱和度又都在 77–88%，视觉上都是暖黄橙。分配算法保证不在同一个 5 人频道里同时选中，但 8 个 Bot 全用时这一对会显得像「同一个人的深浅两版」——这是本方案已知最弱处。若后续扩到 12 色，应把这支暖色合并为一支。
5. **主色 `#0C7A8F` 与 bot-1 钴蓝**在低质量屏上可能接近：主色只做按钮与焦点，不做大面积色块。
6. **动效预算**在弱机上可能掉帧：已限制为单 Turn 动效，但阴影与扫光仍需在 60fps 下实测。
