# 真实产品界面调研（视觉重做的依据）

> 调研日期 2026-10-24。来源：DeepSeekBot 官方 README 截图（v3 界面，2 张：私聊页 + 群聊页），
> 以及 Grok Bot 设计分析文章。**未参考本机任何已有项目代码。**
> 上一版 instrument-panel 方向被用户否决：「直愣直去的，没有圆角卡片，没有动效，看着很生硬」。

## 一、DeepSeekBot 真实界面拆解（有截图实证）

### 布局（三栏）
```
┌────┬──────────────────┬─────────────────────────┬──────────────────┐
│ 56 │ 频道列表 260px   │ 消息流 弹性             │ 右面板 320px     │
│ 图标│ 头像+名字+摘要+时间│ 气泡流                  │ 记忆/成员/工具   │
│ 栏  │                  │                         │                  │
└────┴──────────────────┴─────────────────────────┴──────────────────┘
```

### 具体视觉参数（从截图读出）
| 元素 | 观察到的做法 |
|---|---|
| 底色 | 极浅冷灰白（近似 `#F7F8FA`），不是纯白 |
| 左图标栏 | 56px 宽，顶部品牌标，图标为线性单色，选中项有浅色圆角块底 |
| 频道列表 | 每行：40px 圆形/方形像素头像 + 名称 + 一行摘要 + 右上时间；选中行整行浅蓝灰圆角底（圆角约 10px）；未读有数字或小点 |
| 消息气泡 | **圆角 14–16px**，用户消息实心填充（蓝 `#3B5BDB` 系 / 暖红 `#C0392B` 系两种主题），Bot 消息**浅灰底 `#F1F3F5` 无边框**；气泡内边距约 14×18 |
| 气泡宽度 | 最大约 68–72 字符宽，不会铺满 |
| 头像 | 圆形，32px，位于气泡左侧；Bot 名在气泡上方小字（12px，灰色或彩色） |
| 群聊 | 多个 Bot 依次回复，每个 Bot 独立头像 + 名字 + 气泡；用户消息里可以用 `@Mira` 形式点名多个 |
| 输入框 | **胶囊形（border-radius 约 24px）**，浅灰底无边框，内含回形针图标 + placeholder + 右侧圆形发送按钮（灰底圆角方块，内为 ↑ 箭头） |
| 输入框下方 | 小圆角标签条：模型名（`DeepSeek V4.1 Flash`）、工作区数、token 用量，均带小图标 |
| 右面板 | 顶部 tab 切换（记忆/演化/版本/分支）；内容为文件级条目 + Git 提交图（竖线 + 节点 + 短 hash + `Git 提交` 标签）；无重边框，靠间距和浅色小标签区分 |
| 成员列表 | 头像 + 名字 + `Bot` 小标签 + `...` 菜单 |
| 图标 | 用 emoji 或简洁线性图标，不用复杂自绘 |
| 分隔 | 几乎不用硬边框线，靠背景色差 + 圆角块 + 留白 |
| 阴影 | 极克制：只有输入框、弹层有非常淡的阴影 |

### 交互与动效（从截图推断 + Grok Bot 设计文章佐证）
- Bot 状态用「小圆点」表达（绿=在线/空闲，灰=无消息）
- 消息有流式光标
- 输入框聚焦有边框色变化或轻微上浮

## 二、Grok Bot 设计思路（来自设计团队公开表述）

一篇设计分析提到其核心调整方向，对我们有直接指导价值：

> 「颜色和圆角只是表层，团队调整的是人与智能体之间的关系。**一个 Bot 会经历空闲、思考、工作、等待、受阻和完成。** 像动效提供第一层安心感。」

以及侧栏的演变：

> 「侧栏从按时间排列的会话，变成了**一份角色名册**：Kenny、Justin、John、财务 Bot、销售 Bot、Chief of Staff。每个角色有自己的名字、头像、记忆、工具和电脑。」

**可直接采用的结论：**
1. **Bot 的状态机必须可见**：空闲 / 思考 / 工作 / 等待 / 受阻 / 完成 —— 六态，各有视觉表达。
2. **动效的作用是「安心感」**，不是炫技：让用户知道"它还在动，没死"。
3. **侧栏是名册不是列表**：Bot 应该像同事一样被"认识"，而不是像文档一样被"列出"。

## 三、由此推翻的上一版设计

| 上一版（instrument-panel） | 为什么错 | 新方向要求 |
|---|---|---|
| 全站直角（border-radius ≤6px） | 用户直说"直愣直去" | **圆角 12–18px 为主**，卡片和气泡都要圆 |
| 禁止阴影 | 没有层次感，像表格 | **允许柔和阴影**（`0 1px 3px rgba(0,0,0,.04)` 级别 + 浮层更深） |
| 密排、高信息密度 | 像机房监控，不像 AI 同事 | **留白充足**，每屏信息量下降 |
| 事件轨 + 等宽主导 | 太硬核，非技术用户劝退 | **气泡 + 头像**，事件折叠在气泡下方 |
| 冷灰仪器色 `#0B6E69` | 冷、机械 | **柔和色系**，主色要温润 |
| 无动效 | 生硬 | **必须有动效**：进入、状态变化、流式、按压反馈 |

## 四、新方向的硬性要求（三套候选都必须满足）

1. **圆角**：卡片 ≥12px，气泡 ≥14px，按钮 ≥8px，输入框胶囊化（≥20px）
2. **阴影**：至少两级（卡片 `0 1px 3px`、浮层 `0 8px 24px`），必须柔和低透明度
3. **动效**：必须定义 6 类——页面/区块进入、消息出现、流式光标、状态变化、按钮按压、弹层进出；时长 120–320ms，缓动 `cubic-bezier(.2,.8,.3,1)`
4. **留白**：间距刻度要有 20/24/32/40 这些大值，不是只有 2/4/6/8
5. **Bot 六态**：空闲/思考/工作/等待/受阻/完成，各有颜色 + 图标 + 动效
6. **头像**：Bot 必须有头像位（首字方牌或像素/emoji），在列表、气泡、成员面板统一出现
7. **不用硬边框划分区域**：靠背景色差 + 圆角 + 留白
8. **等宽字体只用于代码/路径/token 数**，正文用无衬线

## 五、三套候选方向的差异化定位

| variant | 气质 | 主色系 | 独特手法 |
|---|---|---|---|
| **soft** | 温柔、亲近、像 Notion/Linear 的柔和版 | 雾蓝 + 暖沙 | 大面积浅色块、极柔和阴影、消息气泡浮起感 |
| **vivid** | 活泼、有性格、像 Discord/DeepSeekBot | 蓝紫渐变点缀 + 高饱和强调 | 像素/emoji 头像、彩色 Bot 标识、明显动效 |
| **calm** | 克制、专业、像 Claude/Arc 的沉静 | 墨绿/暖褐 + 奶油底 | 大留白、细腻字距、几乎无装饰但有呼吸感 |

三套都必须：圆角、阴影、动效、Bot 六态、头像、留白充足。
