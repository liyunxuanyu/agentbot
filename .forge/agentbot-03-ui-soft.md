# AgentBot 视觉设计系统 · soft

> 重做版，替代 `agentbot-03-ui-instrument.md`（被否决：直愣、无圆角、无动效）。依据 `agentbot-ui-research-real.md`、`agentbot-02-ux.md`。令牌见 `agentbot-tokens-soft.css`。

## 1. 方向陈述

像一张摊开的浅灰桌面，Bot 是坐在对面的人。雾蓝负责「它在做事」，暖沙负责「这是你」。卡片和气泡浮在桌面上一毫米，用阴影而不是线说话。牺牲的是密度：同屏比 instrument 少约 30% 行数，扫描式对比让位给逐条阅读；20+ Bot 的批量运维也不是它的强项。

## 2. 色彩系统

### 2.1 表面 4 级

| 令牌 | 值 | 用途 | 为什么 |
|---|---|---|---|
| `--color-bg` | `#EDF1F5` | 页面底、导航、消息流底 | 冷调白，比纯白暗 1.14:1 亮度比，白卡片才浮得起来；不用米色，否则变成纸感 |
| `--color-surface` | `#FFFFFF` | 卡片、Bot 气泡、弹层、输入框 | 纯白 + 阴影 = 浮起。soft 方向的核心手法 |
| `--color-surface-sunken` | `#E4EAF0` | 输入框静息、折叠块、代码块、表头 | 比页面底再深一档，形成「凹」，与白卡片构成浮/凹二象 |
| `--color-surface-hover` | `#F6F8FA` | 白底上的悬停染色 | 只改 2% 亮度，避免悬停看起来像选中 |

### 2.5 Bot 六态色板

**颜色从不单独承载语义**——每态固定「色点 + 图标 + 文字」三元组，满足 UX §8「不靠颜色区分」。

| 态 | 色 | 图标（内联 SVG，非 emoji） | 动效 |
|---|---|---|---|
| 空闲 | `#7A8690` 3.7:1 | 空心圆环 2px | 无。静止本身就是信息 |
| 思考 | `#4E6E8C` 5.3:1 | 三点（3 个 4px 圆） | 三点依次 `opacity .25→1`，1400ms 循环 |
| 工作 | `#2F7A80` 5.0:1 | 270° 圆弧 2px | 弧 `rotate 360deg`，1600ms linear 循环 |
| 等待 | `#A8763C` 3.95:1 | 沙漏（两个三角） | 呼吸 `opacity .6→1`，2000ms 循环 |
| 受阻 | `#A8453F` 5.9:1 | 感叹号（竖线 + 点） | **不动**。静止是唯一的警报语言 |
| 完成 | `#3F7A5A` 5.1:1 | 对勾 | 一次性 `scale 1→1.15→1`，320ms 后静止 |

| h2 | 19 / 1.40 / 600 | 区块标题、弹层标题 |

## 4. 圆角与阴影

### 4.1 圆角（7 级）
| 令牌 | 值 | 用在哪 | 为什么 |
|---|---|---|---|
| `--radius-xs` | 6px | 小徽标、状态胶囊、代码方牌、Session 分隔条 | 徽标只有 22px 高，再圆就成药丸 |
| `--radius-sm` | 10px | 按钮、能力徽标组、小输入 | 36px 高按钮配 10px ≈ 28% 曲率，柔和但不软塌 |
| `--radius-md` | 12px | 频道列表行、导航项、折叠块、Turn 头、40px 头像 | 行高 40–60px 的容器 |
| `--radius-lg` | **16px** | **Bot 卡片、消息气泡**、事件卡片、权限卡片 | 硬指标。内距 20px 时 16px 是「圆但不鼓」的临界值 |
| `--radius-xl` | 20px | 大卡内嵌块、右面板分块 | |
| `--radius-2xl` | **24px** | **输入框胶囊**、弹层、抽屉 | 48px 高输入框用 24px 恰好全胶囊 |
| `--radius-pill` | 999px | 状态点、未读计数、头像叠层边 | 只给 24px 以下的圆形元素 |

**头像曲率规则**：圆角 = 尺寸 × 30%（40px→12，32px→10，24px→8）。同一 Bot 的方牌在列表、气泡、成员面板必须同色同曲率，这是身份锚点。

### 4.2 阴影（3 级，全部低透明度）
| 令牌 | 值 | 用在哪 |
|---|---|---|
| `--shadow-card` | `0 1px 3px rgba(30,42,51,.04), 0 1px 2px rgba(30,42,51,.03)` | Bot 卡片、Bot 气泡、输入框静息 |
| `--shadow-raised` | `0 4px 12px rgba(30,42,51,.06), 0 1px 3px rgba(30,42,51,.04)` | 悬停卡片、吸顶 Turn 头、权限卡片、聚焦输入框 |
| `--shadow-overlay` | `0 12px 32px rgba(30,42,51,.10), 0 2px 8px rgba(30,42,51,.05)` | 弹层、抽屉、@ 选择器 |

阴影色用 `rgba(30,42,51,…)`（= fg-1）而不是纯黑：纯黑阴影在冷灰底上发脏、发黄。透明度的克制是刻意的——卡片靠「白 vs 底」的 1.14:1 亮度差 + 极淡阴影共同浮起，单靠任一项都不够。

## 5. 间距与栅格

### 5.1 刻度（基准 4px）

| 令牌 | 值 | 典型用途 |
|---|---|---|
| `--space-1…3` | 2 / 4 / 6 | 图标与文字间隙、徽标内距 |
| `--space-4…6` | 8 / 12 / 16 | 组件内距、行内元素间距 |
| `--space-7…9` | **20 / 24 / 32** | 卡片内距、区块间距、页面边距 |
| `--space-10…12` | **40 / 48 / 64** | Turn 间距、空态上下留白、页面顶底 |

### 5.2 栅格与留白规则

- 三栏：导航 240 / 消息流弹性 / 右面板 320，`gap: 0`，靠 `--color-bg` 透出 20px 缝——**不用边框分栏**。
- 页面内边距：≥1280 用 32px；768–1280 用 24px；<768 用 16px。
- `/bots` 网格：≥1280 三列 `gap 20px`；1024–1280 两列；<768 单列。
- 气泡最大宽 `min(68ch, 640px)`；375px 下 `calc(100vw - 40px)`，两侧各留 20px 呼吸。
- **Turn 之间 40px，Turn 内事件之间 12px，同一 Bot 连续气泡之间 8px**——层级只靠间距区分，不画分隔线。
- 内容密度上限：一屏（900px 高）最多 2 个展开 Turn + 3 个折叠 Turn。这是对 instrument 版「一屏塞 6 轮」的直接反拨。

## 6. 动效系统

主缓动 `--ease-out: cubic-bezier(.2,.8,.3,1)`；另有 `--ease-in: cubic-bezier(.4,0,1,1)`、`--ease-pop: cubic-bezier(.34,1.4,.64,1)`（只给「完成」用）、`--ease-standard: cubic-bezier(.2,0,0,1)`。

| # | 类别 | 时长 | 缓动 | 属性变化 | 触发 |
|---|---|---|---|---|---|
| 1 | 页面/区块进入 | 240ms | ease-out | `opacity 0→1` + `translateY 8px→0`；同组元素逐项延迟 40ms，最多 4 项 | 路由切换、标签切换、首屏 |
| 2 | 消息气泡出现 | 220ms | ease-out | `opacity 0→1` + `translateY 6px→0` + `scale .985→1` | 新消息落位（历史重载不播） |
| 3 | 流式光标 | 900ms | ease-in-out | 2px×16px 竖条 `opacity .2→1` 无限循环；结束 120ms 淡出 | 增量事件期间 |
| 4 | Bot 状态变化 | 200ms | ease-out | 色点 `background-color` 过渡 200ms、图标 `scale 1→1.15→1`；思考三点 1400ms、工作弧 1600ms linear、等待呼吸 2000ms | SSE 状态事件 |
| 5 | 按钮按压 | 120ms | ease-out | `scale 1→.97` + 底色 → active；松开 160ms ease-pop 回 1 | `:active` |
| 6 | 弹层进出 | 进 260 / 出 180 | 进 ease-out / 出 ease-in | `opacity`、`translateY 12px→0`、`scale .98→1`；遮罩 opacity `0→.24` | 打开 / 关闭、抽屉 |

附加约束：悬停位移最大 1px（`translateY(-1px)`）+ 阴影 card→raised，不做放大；状态色变化 200ms 交叉淡入，不闪；**不做**滚动视差、粒子、渐变流动、自动轮播。

### 6.1 `prefers-reduced-motion` 降级

`--dur-fast/base/slow/xslow` 全部置 `0.01ms`，`animation-duration` 与 `transition-duration` 同步降为 `0.01ms`；关闭光标闪烁（改为静态 2px 竖条）与三点/旋转/呼吸循环（改为静态图标）；保留颜色变化与焦点环（它们是信息，不是装饰）；弹层直接显隐，不做位移。

## 8. 关键页面视觉规格

### `/bots`
页面底 `#EDF1F5`，内距 32。标题区 32/600；汇总行 14 fg-2「6 个 Bot · 3 种运行时 · 2 个执行中 · 3 条待批」；筛选条为胶囊 chip 高 32 radius 10，选中 `primary-weak`。卡片网格 3 列 gap 20，白卡内距 20：40 头像 + 名称 16/600（右上待批徽标 6px `warning-weak`）→ 人格摘要 14 fg-2 单行 → 运行时徽标行 13（文字，非色块）→ 执行位置 13 等宽 fg-3 → 状态点 +「空闲 · 2h 前」。背景只有两层（bg / surface），卡片间 20px 缝隙露底色，零边框。

### `/chat/:channelId`
三栏 `240(bg) │ 弹性(bg) │ 320(surface, radius 20, 浮起)`。消息流内距 32/24，自上而下：会话头 44 → Session 分隔条（仅变化时）→ Turn（间距 40：吸顶 Turn 头 → Bot 白气泡带影 → 灰色折叠事件 → 无底用量行）→ 用户暖沙气泡靠右 → 权限卡 sticky → 输入胶囊 48px。**暖/冷、实/浮的对照就是「谁在说」的全部编码**：Bot 白底带影（浮起），用户暖沙无影（沉下）。权限卡片吸在输入区上方 16px，与输入框同时可见；输入区下方 12px 是模型 / token 标签条（12 fg-3）。

### `/usage`
筛选条为胶囊 chip 组 gap 8；三张聚合白卡（总请求 / 输入 / 输出）16 圆角、数字 24/600 tabular；表格无外框，表头 12 fg-3 于 `surface-sunken` 上圆角 12，行高 52、悬停 `surface-hover`、数字右对齐等宽；未上报单列于表格下方独立白卡（warning 图标 +「N 个运行时未上报」）。**不做密集表格**：列宽靠内距 16 撑开，一屏最多 12 行。

## 9. 与 UX 五原则的对应

| 原则 | 视觉落点 |
|---|---|
| 1 Bot 是主角 | 40px 头像是全站最大图形元素；运行时只做 12px 文字徽标，永不做色块或图标 |
| 2 能力可见而非缺失 | 能力徽标三态都带文字（支持/未知/不支持）；未知用中性灰，不隐藏也不置灰到不可读 |
| 3 治理在主流程内 | 权限卡片以 raised 阴影插入消息流，视觉重量高于普通气泡；三态靠左竖条区分而非颜色 |
| 4 一次只展开一层 | 折叠块 36px 高 + 无阴影（凹）；只有 1 / 6 / 9 类事件用白卡 + 阴影占据视觉主导 |
| 5 缺席要可解释 | 空态 = 头像叠层 + 一句「为什么」+ 一个动作；未发言 Bot 用 fg-3 一行说明，不做成警告 |

## 10. 局限与风险

1. **低对比的代价**：`#EDF1F5` 与 `#FFFFFF` 只有 1.14:1 亮度差，全靠阴影。老 TN 屏或强反光下卡片边界会消失。缓解：阴影不低于 `0 1px 3px .04`，卡片间距 ≥20px。
2. **阴影叠加**：悬停卡 + 吸顶 Turn 头 + 权限卡同屏会脏。规则：同一视口最多两个 raised。
3. **暖沙用户气泡与 warning 色同属暖调**，密集出现可能误读。缓解：气泡是大面积 `#EDE4D5`（L≈78%），warning 只出现在 8px 点或 3px 竖条上，尺度完全不同。
4. **15px + 1.65 行高**让长回复变长，1000 条消息的滚动成本上升；靠 Turn 折叠解决，不靠缩字号。
5. **暗色主题是附加项**，未做完整对比度实测，只保证结构与令牌映射；上线前需单独验证六态色在深底上的可辨性。
6. **动效依赖 SSE 状态事件**：上报频率低于 1s 时状态点会看起来跳变；建议服务端对状态做 300ms 防抖聚合。
