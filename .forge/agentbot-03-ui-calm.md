# AgentBot 视觉设计系统 · calm

> variant `calm`。输入：`agentbot-ui-research-real.md`、`agentbot-02-ux.md`、`agentbot-01-prd.md`。令牌：`agentbot-tokens-calm.css`。

## 1. 方向陈述

AgentBot 是常驻身边的 AI 同事，一天开 8 小时。calm 的目标不是被看见，是**不被注意**：一间安静的办公室，东西都在该在的位置，但不会喊你。手段是大留白、温润的墨绿灰、几乎看不见的阴影、比常规慢一档的动效。

**牺牲**：信息密度低，20 个 Bot 要滚动；低饱和色在强光下不够跳；慢动效在连续操作时略拖。**这个方向可能不够有活力**——要「打开就有反应」的爽感，它给不了。

**关键词**：呼吸 / 温润 / 不抢注意力

**只属于这个产品的决定**：墨绿只出现在**可执行的东西**上——主按钮、当前导航、流式光标、正在工作的 Bot。其余全是墨绿灰阶。**颜色即许可。**

## 3. 字体系统

| 令牌 | 值 |
|---|---|
| `--font-sans` | `"Inter", "PingFang SC", "Noto Sans SC", "Segoe UI", -apple-system, sans-serif` |
| `--font-mono` | `"JetBrains Mono", "SF Mono", "Cascadia Code", ui-monospace, monospace` |

**字重只用 400 / 500。** 600/700 在暖底上显得吵；标题靠字号与字距建层级，不靠加粗。

| 级别 | 字号 | 字重 | 行高 | 字距 |
|---|---|---|---|---|
| display | 32px | 500 | 1.30 | -0.02em |
| h1 | 26px | 500 | 1.35 | -0.015em |
| h2 | 20px | 500 | 1.40 | -0.01em |
| h3 | 17px | 500 | 1.45 | -0.005em |
| body-lg | 16px | 400 | 1.70 | 0 |
| body | 15px | 400 | 1.75 | +0.01em |
| small | 13px | 400 | 1.60 | +0.01em |
| micro | 12px | 400 | 1.50 | +0.02em |
| label | 11px | 500 | 1.40 | +0.04em |

**字距规则**（calm 的细腻感主要来自这里）：字号越大越收紧（32px 收 -0.02em，17px 只收 -0.005em），小字号反而放开；中文正文必须 +0.01em，0 字距下中文显得挤；11px 标签 +0.04em，但**不做全大写**（全大写读作装饰）；等宽只用于代码、绝对路径、命令、token 数字，token 加 `tabular-nums` 且字距 0；中英混排不加空格，靠字距处理。

## 4. 圆角与阴影

| 令牌 | 值 | 用途 |
|---|---|---|
| `--r-badge` / `--r-btn` | 6px / 10px | 徽标与小标签、未读计数 / 按钮、导航项、chips、表格行 |
| `--r-block` / `--r-card` | 14px / 18px | 折叠块、列表行、输入内槽 / Bot 卡片、权限卡片、弹层 |
| `--r-bubble` / `--r-pill` | 18px / 26px | 消息气泡（四角相同，不做出尖角）/ 输入胶囊、筛选 pill |
| `--r-full` | 999px | 状态点、发送按钮 |

| 令牌 | 值 | 用途 |
|---|---|---|
| `--shadow-card` | `0 1px 2px rgba(63,97,82,.03)` | 卡片、Bot 气泡 |
| `--shadow-raised` | `0 3px 10px rgba(63,97,82,.05)` | 卡片悬停、权限卡片、输入胶囊 |
| `--shadow-overlay` | `0 10px 28px rgba(63,97,82,.08)` | 弹层、下拉、待批浮层 |

**分工**：色阶负责「这是什么层」，阴影负责「它离你多近」。阴影淡到几乎看不见是有意的——只在视线移动时确认层级，不参与构图。两者都保留，色阶为主、阴影为辅。

## 5. 间距与栅格

| 令牌 | 值 | 典型用途 |
|---|---|---|
| sp-1…sp-3 | 4 / 8 / 12 | 图标与文字、气泡内事件间距 |
| sp-4 / sp-5 | 16 / 20 | 卡片内行距、按钮内边距 |
| sp-6 / sp-7 | 24 / 32 | 卡片内边距、卡片间距、消息流左右 |
| sp-8 / sp-9 | 40 / 48 | Turn 间静音间隙、页面顶部 |
| sp-10 / sp-11 | 64 / 80 | 空态上下、页头到内容 |

**栅格**：12 列，列间距 32px，页边距 40px（<1280 降 32px，<768 降 20px），内容最大宽 1180px，消息流最大宽 720px 居中。

**留白规则（calm 的主角）**：**Turn 之间必须 40px**，这是呼吸节拍，同 Turn 内事件之间 12px——靠留白分辨轮次，不用分隔线；卡片内边距 24px 起，永不低于 16px；页头到第一块内容 40px，空态上下各 64px；右面板块间 32px、块内 12px；两个不同性质区域之间至少 24px，放不下就换行，不压缩。

## 6. 动效系统

统一缓动 `--ease-calm: cubic-bezier(.25,.1,.25,1)`（标准缓入缓出，**无回弹**）。比常规慢一档，因为快动效读作「系统在抢话」。下表是**过渡**时长（180–400ms）；另有 4 个**持续循环**（光标 1.1s、思考 2.4s、外环 2.8s、等待 3.2s），只表示「还活着」，不表示状态切换。

| # | 类别 | 规格 |
|---|---|---|
| 1 | 页面/区块进入 | opacity 0→1 + translateY 8px→0，**400ms**；同级 stagger 60ms，最多 4 个 |
| 2 | 消息气泡出现 | opacity + translateY 6px + scale .995→1，**280ms** |
| 3 | 流式光标 | 1.1s 明暗循环（opacity 1↔.15，ease-in-out），**不用 steps 闪烁** |
| 4 | Bot 状态变化 | 点色 crossfade **240ms**；工作态外环 2.8s 扩散；思考态三点 2.4s 错峰 |
| 5 | 按钮按压 | scale .985 + 背景过渡 **180ms**；悬停 180ms |
| 6 | 弹层进出 | 进：opacity + translateY 12px + scale .99，**320ms**；出：**180ms** |

**`prefers-reduced-motion: reduce`**：取消所有 transform（只留 opacity），进入类统一 1ms，光标改静态 2px 竖线，外环与三点动画停止（状态靠颜色 + 文字表达）。

## 9. 与 UX 五原则的对应

| 原则 | 视觉落点 |
|---|---|
| 1 Bot 是主角 | 头像 40px 在卡片首行、28px 在 Turn 头与气泡旁；运行时只做 22px 徽标，永远在名字之后 |
| 2 能力可见 | 徽标三态用前缀（? / 无）区分未知与不支持，颜色只做辅助；流中不出现未声明事件的任何占位 |
| 3 治理在主流程内 | 权限卡片是流内唯一的 `shadow-raised` 元素；阻断态用 warning-soft 整块，不靠边框喊人 |
| 4 一次只展开一层 | 折叠块 36px 高、s1 底，视觉权重低于气泡；展开用 240ms 高度动画，不弹窗 |

## 10. 局限与风险

1. **信息密度低**：168px 卡片 + 24px 间距，1440px 下 3 列只放 6 张，20+ Bot 需滚动。缓解：汇总条先给数字（`6 个 Bot · 3 种运行时 · 2 个执行中`），筛选 pill 常驻；>20 Bot 时卡片压到 148px 并隐藏人格摘要（PRD Q2 已决保留网格）。
2. **留白吃屏幕**：1280 笔记本上 40px 页边距 + 24px 栏距会显得内容偏窄。已在断点把页边距降到 32px、消息流 640px。
3. **低饱和主色不跳**：强光或低色域屏上墨绿会发灰。因此正文一律 text-1（13.6:1），主色只做填充与选中，不承载小字。
4. **慢动效有代价**：连续展开/折叠时 280–400ms 会略拖。已把交互反馈压到 180–240ms，只有区块进入用 400ms。
5. **极淡阴影在廉价屏几乎不可见**：所以层次主要靠 4 级表面色差，阴影只做确认。这是刻意的冗余。
6. **可能不够有活力**：要「打开就有反应」的爽感，calm 给不了。它的价值是开一整天不烦。
