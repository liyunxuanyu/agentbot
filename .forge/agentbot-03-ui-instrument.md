# AgentBot 视觉设计系统 · instrument-panel

> 变体 `instrument`。输入：`agentbot-02-ux.md`、`agentbot-01-prd.md`、`agentbot-00-brief.md`、`board/product-positioning/03-decisions.md`。
> 令牌：`agentbot-tokens-instrument.css`。

## 1. 设计方向

**气质**：工程图纸与机架面板的合体——冷灰底、1px 网格、等宽读数、LED 状态灯。

**为什么适合**：产品核心动作是「观测多个正在运行的进程」，不是「浏览条目」。S3 要求一屏说清每个 Bot 在哪个 agent 上跑；把信息排成**测量**而不是**卡片**，纵向扫一列就等于读一台机器的仪表。

**牺牲**：温度与社交感。群聊里「AI 同事」的人际隐喻被削弱，非技术用户第一眼会觉得像机房监控（缓解见 §9）。

**关键词**：测量 / 秩序 / 静默运转

## 2. 色彩

### 2.1 表面 4 级（浅色默认）

| 令牌 | 值 | 用途 | 说明 |
|---|---|---|---|
| `--color-surface-0` | `#E4EAEC` | 页面底 | 冷灰白（H195 S17% L91%），仪器喷涂面，**不是**纯白也不是暖白 |
| `--color-surface-1` | `#DDE4E7` | 导航栏、表头、斑马行、折叠块底 | 比页面**深**：铣出来的凹槽。这是"面板"而不是"纸"的关键 |
| `--color-surface-2` | `#F8FAFB` | 卡片、面板 | 比页面**亮**：卡片像贴在面板上的读数条，凸起 |
| `--color-surface-3` | `#FFFFFF` | 输入框、浮层、吸顶 Turn 头 | 唯一纯白，只给需要「浮起」的两处 |

四级构成一条真实的物理层级：凹槽（深）→ 面板（中）→ 读数卡（亮）→ 浮层（白）。任何元素落在哪一级，都由它的物理关系决定，不靠阴影堆叠。

**暗色映射**（同一物理关系，整体反相）：s0 `#0F1517` / s1 `#0A1011`（更暗的凹槽）/ s2 `#1C2528`（更亮的卡片）/ s3 `#232E31`。暗色不是默认主题——仪器面板在明亮机房里就是浅灰的，暗色是夜间值守的选项。

| 令牌 | 浅色 | 压字色 | 深色 | 用途 |
|---|---|---|---|---|
| `--color-accent` | `#0B6E69` | `#F8FAFB` **5.8:1** | `#3FB3A8` | 主操作、当前项、工具调用 |
| `--color-accent-hover` | `#085C58` | 同上 | `#52C2B7` | 悬停 |
| `--color-accent-active` | `#064B48` | 同上 | `#2E9A90` | 按下 |
| `--color-accent-weak-bg` | `#D3E6E3` | `#0A5C58` **6.0:1** | `#12312F` | 选中行底纹 |
| `--color-success` | `#26713A` | `#FFFFFF` 6.0:1 | `#3FAE79` | 成功、已完成、工具结果成功 |

| `--color-danger` | `#B33127` | `#FFFFFF` 6.2:1 | `#E8756A` | 失败、错误、危险操作 |

所有语义色在 s0/s1/s2/s3 四级表面上均 ≥4.6:1（最低：浅色 `warning` 对 s1 的 4.61:1、暗色 `info` 对 s3 的 4.61:1）。正文与次要文字对全部表面 ≥4.5:1；`fg-4` 是唯一低于 4.5 的前景，按 WCAG 仅用于禁用态。

**主色选型理由**：`#0B6E69` 落在示波器荧光与面板指示灯的传统青绿区间（H178 S82% L24%）。冷灰底上 5.0:1 可直接做文字；不与红（失败）、琥珀（待决策）抢语义；比纯蓝少「超链接」联想，比橙少「告警」联想。**明确不用**：紫/靛蓝（SaaS 默认，且与告警色混淆）、纯蓝 `#2563EB`（读作链接）、橙红（独占告警语义）、绿（独占成功语义）。

### 2.5 指示灯（LED）

6px **方块**（不是圆点——方块更像面板元件），右距 4px 接状态文字。**任何状态都必须带文字**（UX §8：不靠颜色区分状态）。所有 LED 对其所在表面 ≥3:1。

六色分工逻辑：青＝正在做功（与主色同族但亮一档，避免和主按钮抢眼）；灰＝没在做功；蓝灰＝在队列里等（冷、被动，区别于"空闲"但不报警）；琥珀＝等你；红＝坏了；绿＝成了。**只有琥珀闪**，因为只有它要求你立刻行动。

| 状态 | 浅色 | 深色 | 动效 |
|---|---|---|---|
| 运行中 / 生成中 | `#0A847C` | `#3FB3A8` | 呼吸 2s `ease-in-out`（不闪） |
| 空闲 | `#68767A` | `#8A989C` | 常亮 |
| 排队中 | `#4A6C82` | `#6E9AB5` | 常亮，文字后缀「前序 2」 |
| 待决策（待批） | `#A87200` | `#D8A03A` | **闪烁 1.4s `steps(2)`——全局唯一允许闪的状态** |
| 失败 / 不可用 | `#B33127` | `#E8756A` | 常亮（错误不闪，闪会疲劳） |
| 已完成 | `#26713A` | `#3FAE79` | 常亮 |

符号均为等宽单字形，落在 20px 事件槽中央，纵向构成一条可扫读的轨道。

| 用量 | `fg-3` | `∑` | 极轻，单行 |

## 3. 字体

| 令牌 | 值 |
|---|---|
| `--font-sans` | `"IBM Plex Sans", "Segoe UI Variable Text", "Segoe UI", "Noto Sans SC", "Microsoft YaHei UI", -apple-system, sans-serif` |
| `--font-mono` | `"IBM Plex Mono", "Cascadia Mono", Consolas, "SF Mono", "Noto Sans Mono", monospace` |

**双族理由**：Plex 是 IBM 为工程与技术界面设计的，字形略方、字面偏窄、数字真等宽，天然带「设备感」；无衬线负责读句子，等宽负责读**量**。同厂同骨架，混排不打架。IBM Plex Sans（400/500/600）+ Mono（400/500）以 woff2 本地打包（≈180KB），因为产品离线运行、不能依赖 CDN；中文回退 Noto Sans SC / 微软雅黑。

| 级别 | px / 行高 | 字重 | 用途 |
|---|---|---|---|
| `--text-2xs` | 10 / 14 | 600 | 大写字段名（`RUNTIME` `LOCATION`），字距 0.08em |
| `--text-xs` | 11 / 16 | 500 | 徽标、时间戳、事件摘要、LED 文字 |
| `--text-sm` | 12 / 18 | 400 | 表格单元格、路径、次要行 |
| `--text-md` | 13 / 20 | 400 | 基础 UI：导航、按钮、表单、卡片读数 |
| `--text-lg` | 15 / 22 | 400 | 消息正文（唯一为长文阅读让步的一级） |
| `--text-xl` | 20 / 26 | 600 | 区块标题、读数条数字 |
| `--text-2xl` | 26 / 32 | 600 | 页面标题 |
| `--text-3xl` | 34 / 40 | 600 | 仅页头读数主数字 |

**数字排版**：所有数值列 `font-variant-numeric: tabular-nums` + `font-feature-settings:"tnum" 1`，**右对齐**；单位（`token`/`s`/`%`）用 `fg-3`、字号 ×0.9、与数字间留 2px。数值与标签用空格分隔不用冒号：`1,204 in` 而非 `in: 1,204`。
**标签排版**：小号大写 + 0.08em 字距**只用于列头与字段名**；按钮、标题、导航一律 sentence case——大写是少数派，才有信号价值。

## 4. 间距与栅格

刻度：`2 / 4 / 6 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48 / 64`（基准 4px；2 只用于 LED 与数字-单位间隙）。12 列栅格，gutter `16px`，内容最大宽 `1440px`，页面内边距 `24px`。

**跨卡片对齐（本方向的核心技术决定）**：Bot 卡片内部固定 `grid-template-columns: 64px 1fr`，64px 标签列在所有卡片中相同 → 三行读数在网格里**天然共线**，横向扫一眼就是一列运行时、一列执行位置、一列 Session 状态。卡片高度锁 `172px`，保证同一行的卡片基线齐平。值列等宽 + 数字右对齐。

**刻度与参考线规范**。用：①页头读数条下的 1px 通栏线；②表格列间 1px 竖线；③会话流左侧 20px 事件轨；④数值列头的 5 个 1px 刻度。不用：卡片内部、按钮四周、空态、表单里——那会变成装饰噪声。

## 6. 关键页面

**`/bots`**（S3 主战场）
```
[ 页头 64px ]  6 BOTS │ 3 RUNTIMES │ 2 RUNNING │ 3 AWAITING      [+ 新建 Bot]
────────────────────────────────────────────────────────────── 1px border-1
[ 筛选 40px ]  RUNTIME 全部 Gemini Codex CC    STATUS 全部    LOCATION 全部   6/6
──────────────────────────────────────────────────────────────
[ 网格 ] repeat(auto-fill, minmax(360px,1fr))  gap 16px
         ≥1280 三列 · 1024–1280 两列 · <1024 一列
```
页面底 `surface-0`，卡片 `surface-2`（卡比页亮）。页头是四个读数而非四个统计卡：数字 20px 等宽、标签 10px 大写、组间竖线——第一眼就是一台机器的面板。卡片高度锁死，网格行基线永远齐平。筛选无结果时保留读数条与筛选条，只在网格区显示一行 + 「清除筛选」。

**`/chat/:channelId`**：左 240（`surface-1`，右 1px）｜中弹性（`surface-0`）｜右 320（`surface-2`，左 1px）。会话头 48px：群聊＝参与者方牌行 + `主持人：研究助手 [更换]`；单聊＝方牌 + 名称 + 运行时徽标 + 执行位置（等宽 11，中段省略）。**消息流左侧贯穿一条 1px 事件轨**，所有事件符号落在轨上——整段对话是一条连续记录带，不是一堆气泡。Turn 头吸顶 `surface-3`。

**`/usage`**：筛选条 → 表格 → 合计行。每个数值列头下加一条 5 刻度小尺（宽 40px、1px tick、间距 8px），标出该列当前最大值量级——用刻度替代图表，符合「测量」隐喻且零图表依赖。headless 行在 token 数右侧用 `fg-3` 标 `×3`。**未上报显示 `—` 不显示 `0`**：0 是测到的，`—` 是没测到。

## 7. 动效

| 场景 | 规格 |
|---|---|
| 流式光标 | 1.1s `steps(2, end)`，opacity 1↔0（方块光标，不是竖线） |
| 事件出现 | 120ms `ease-out`，opacity 0→1 + translateY 2px→0（只对新事件，历史重放不动） |
| 权限卡片进入 | 180ms `cubic-bezier(.2,.8,.3,1)`，translateY 8px→0 + opacity |
| 状态灯变化 | 颜色 240ms `linear`；运行中呼吸 2s `ease-in-out`；待决策闪烁 1.4s `steps(2)` |

`prefers-reduced-motion: reduce`：光标常亮 60% 不闪；事件与卡片无位移、直接出现；LED 呼吸改静态 + 1px 外环，闪烁改静态实心外框。

## 8. 与 UX 五原则的对应

| 原则 | 视觉落点 |
|---|---|
| 1 Bot 是主角，运行时是属性 | 卡片 60% 面积给身份（名称 15/600 + 人格摘要行），运行时是**读数行**不是徽标墙；左导航没有「运行时」入口 |
| 2 能力可见而非缺失 | 能力徽标三态制：支持 / 不支持 / **未知=虚线**；事件流里未声明的类型完全不存在——没有灰块、没有占位、没有禁用按钮 |
| 3 治理在主流程内 | 权限卡片是流内元素（坐在事件轨上），不是浮层；阻断态用左 3px 竖条 + 输入框锁定，物理上「卡住」这一轮 |
| 4 一次只展开一层 | 卡片无事件、Turn 无参数、折叠块默认 28px；密度靠**对齐**获得，不靠一次性铺开 |
| 5 缺席要可解释 | 空位一律 `—` 加一句原因；未上报用量 `—` 而非 `0`；不可用是顶部细横幅而非整卡变灰——卡片仍在，只是这一项没读数 |

## 9. 局限与风险

| 风险 | 缓解 |
|---|---|
| **冷**：U4/U5 非技术用户面对高密度网格有压力 | `/setup` 向导内把 instrument 语言降到 60%：单列、宽行高、只显示三步，读数条不出现 |
| **移动端**：四字段在 375px 会挤爆一行 | 按 UX §7 保持 5 行不删字段：标签列 64→52px、值字号 12→11px、内边距 16→12px、路径行中段省略（保留 `wt/` 前缀与末 2 段）。不做横向滚动；`/usage` 转列表，每项只留两个数值 |
| **群聊人际感缺失**：无气泡无头像，多人对话像日志 | Turn 头吸顶 + 方牌用 accent 的 6 个明度档区分 Bot + 每轮小结保留自然语言 |
| **状态色对色盲不友好** | LED 一律配文字；形状辅助（待决策方块带外框、失败方块带斜杠）；运行时**从不**用颜色区分 |
| **13px 基准对 40+ 用户偏小** | 提供 `data-text-scale` 三档，只放大字号不动间距 |

**最易被误用的两个令牌**：`--color-fg-4`（会被当成"浅一点的正文字"，但它只有 3.47:1，只能用于禁用态与装饰）；`--color-border-1` vs `--color-border-2`（前者是 1px 分隔线，后者是组件轮廓——混用会让同一页面出现两种"重量"的线，instrument 的秩序感立刻塌掉）。
