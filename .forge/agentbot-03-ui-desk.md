# AgentBot 视觉设计系统 · dispatch-desk（调度台 / 编辑部）

> variant = desk。输入：`agentbot-02-ux.md`、`agentbot-01-prd.md`、`agentbot-00-brief.md`、board `product-positioning/03-decisions.md`。令牌：`agentbot-tokens-desk.css`。

## 1. 设计方向

**气质**：一间有人上班的编辑部——派工单、签派单、红笔、印章，每个 Bot 有自己的名牌和交办记录；核心动作是派活与交付，不是聊天。**关键词**：单据 / 署名 / 规则线 / 印章。

**为什么适合**：Bot 是同事、Assignment 是派活、权限是签字，三件事天然是文书动作，用户判断「谁在做什么、谁签的字」零学习成本。

**牺牲**：不如深色终端「技术」，对硬核 CLI 用户不够酷；暖底衬线在暗光下不如暗色舒适；单据结构吃横向空间，窄屏须转纵向字段。

**标志性决定**：**派工单编号**。Assignment / 权限请求 / 定时任务各带可见等宽编号（`№ A-0142` / `№ P-0031` / `№ S-0007`），印在单据右上角。全站唯一装饰性元素，且真有用——群里可说「看 P-0031」，审计表可按编号查。其余一切克制。

## 2. 色彩

**表面四阶**（暖象牙，明度差 ≤6%，靠规则线分界不靠阴影）：`--color-paper` `#F2EEE2` 页面底｜`--color-sheet` `#FAF7EF` 单据/卡片/输入区｜`--color-alt` `#EBE6D8` 侧栏/表头/斑马行｜`--color-sunk` `#E2DCCB` 代码块/展开内容/禁用字段。

**前景四级**（对比度对 `--color-paper` 实测）：
| 令牌 | 值 | 对比度 | 用途 |
|---|---|---|---|
| `--color-ink-1` | `#221C16` | **14.53:1** | 正文、标题 |
| `--color-ink-2` | `#4A4034` | **8.73:1** | 次要正文、表格内容 |
| `--color-ink-3` | `#6A5F50` | **5.38:1** | 元信息、时间、用量 |
| `--color-ink-4` | `#857963` | **3.69:1** | 仅占位符 / 禁用态 / ≥24px 大字，**禁止正文** |

禁用态对 sheet 3.99:1、对 sunk 3.12:1（非文本 3:1 达标）；正文场景的禁用改用 ink-3 + 50% 不透明度，不降色值。

**主色**：`--color-primary` `#8C4A1C`（on paper 5.82:1）主操作/激活/链接｜`--color-primary-hover` `#74390F`（7.76:1）｜`--color-primary-soft` `#F0E2D1`（其上 primary 文字 5.30:1）｜`--color-on-primary` `#FBF8F0`（对 primary 6.36:1）｜`--color-mark` `#B4431F`（4.99:1）红笔：编号、批注、权限标记，仅 ≥14px 或非正文。

**为什么砖红/焦糖**：`#8C4A1C` 是「红笔压在暖纸上」的色相，饱和度 62%，不跳成警示红；落在印章油墨与咖啡渍之间，在暖底上天然成立。**不用**：蓝（冷色把暖底打成脏黄，且是另一 variant 的地盘）；纯红 `#DC2626`（系统错误色，会被读成「坏了」）；橙（与 warning 撞）。

**语义色**（实色 / 浅底 / 实色 on paper / 浅底上文字）：成功 `#3D6B3A` / `#E2ECDD` / 5.38 / 6.62｜警告 `#8A6410` / `#F2E8D0` / 4.63 / 5.23｜危险 `#A8331E` / `#F5DFD9` / 5.73 / 6.59。

**印章色板**（形状也承担区分，不只靠色）：
| 状态 | 文字 / 底 | 形状 | 对比度 |
|---|---|---|---|
| 已批准 | `#2C5A2E` / `#E2ECDD` | 实心 + 1px 实线 | 6.62 |
| 已拒绝 | `#8E2A18` / `#F5DFD9` | 实心 + 1px 实线 | 6.59 |
| 排队中 | `#7A5A0E` / 透明 | 1px **虚线**框（像未填的表单） | 5.49 on paper |
| 执行中 | `#8C4A1C` / `#F2E4D4` | 实心 + 左 2px 主色条 | 5.41 |
| 挂起中 | `#4A4034` / `#EDE6D6` | 实心 + 上下 1px 双线 | 8.14 |
| 超时 | `#85571A` / 透明 | 1px 虚线 + 右上缺口 | 5.36 on paper |
| 已完成 | `#3F4438` / `#E6E7DC` | 实心 + 1px 实线 | 8.03 |
| 已失效 | `#6B6051` / `#EDE9DE` | 实心 + 文字删除线 | 5.07 |

**九类事件**（符号是字符，非 emoji）：1 消息增量＝无符号·ink-1·展开流式｜2 思考＝`≡`·ink-3/底 sunk·折叠一行｜3 工具调用＝`▸`·ink-2 + 工具名 mono·折叠｜4 工具结果＝`└`·成功 `#3D6B3A`/失败 `#A8331E`·挂在调用下｜5 计划＝`◇`·primary·折叠｜6 权限请求＝`▣`·mark·单据卡片｜7 用量＝`№`·ink-3 mono·单行｜8 结束＝`∎`·ink-3·状态戳｜9 错误＝`×`·danger·常显。未声明的事件类型**不渲染任何占位**（能力掩码，board 03 已决）。

## 3. 字体

| 令牌 | 值 | 理由 |
|---|---|---|
| `--font-serif` | `"Spectral", "Source Serif 4", "Noto Serif SC", "Source Han Serif SC", "Songti SC", "SimSun", Georgia, serif` | Spectral 为屏幕正文设计，笔画端头是硬朗的板状收笔，19px 仍清楚，读起来是「公文」不是「文学」；不用 Playfair / Didot 那类时装衬线，也不用 Georgia 单打（太像旧网页） |
| `--font-sans` | `"IBM Plex Sans", "Public Sans", -apple-system, "Segoe UI", "PingFang SC", "Microsoft YaHei", "Noto Sans SC", sans-serif` | Plex 的方切收笔读起来像仪表盘而不是 App，与 mono 同源；**刻意不用 Inter**（AI 生成界面的默认脸） |
| `--font-mono` | `"IBM Plex Mono", "JetBrains Mono", "SF Mono", "Cascadia Mono", "Consolas", monospace` | 路径 / 命令 / 编号 / token 数——**绝不做正文**；与 Plex Sans 同族保证混排不打架 |

| 级 | 字号 | 行高 | 字重 | 族 | 用途 |
|---|---|---|---|---|---|
| display | 34 | 1.15 | 600 | serif | 页面主标题、Bot 详情名 |
| title | 25 | 1.25 | 600 | serif | 区块标题、报告标题 |
| heading | 19 | 1.32 | 600 | serif | 单据表头、Bot 卡片名 |
| subhead | 16 | 1.45 | 500 | serif | 引文、空态引导、主持人理由 |
| body | 15 | 1.65 | 400 | sans | 消息正文、表单值 |
| small | 13 | 1.55 | 400 | sans | 元信息、次要说明 |
| micro | 11.5 | 1.4 | 500 | sans | 字段标签、印章文字（字距 +0.04em） |
| code | 13 | 1.6 | 400 | mono | 代码块、命令 |
| data | 12 | 1.5 | 500 | mono | 路径、编号、token 数 |

**分工规则（不留模糊地带）**：衬线＝所有 h1–h3、单据表头、Bot 名、Assignment 标题、报告小标题、空态引导句、轮次栅栏。无衬线＝消息正文、表单值、按钮、导航、表格单元格、说明、印章文字、字段标签。等宽＝路径、命令、单据编号、token 数、耗时、exit code、代码块；表格里的普通数值用 sans + `tabular-nums`。边界：Bot 名衬线而其运行时徽标 sans；Assignment 标题衬线而其编号 mono。

## 4. 间距与栅格

刻度 2 / 4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 / 80（基准 4）。侧栏 240px（1024–1280 收 64px 图标栏）｜主区弹性，正文宽上限 **68ch / 720px**｜右面板 320px。Bot 网格 ≥1280 三列、1024–1280 两列、768–1024 一列。断点：`<640` 单列（字段行转纵向）/ `768` 双列 / `1024` 图标栏 / `1280` 三列 + 常驻右面板。

**规则线系统（替代阴影）**：hair 1px `#D8D0BC` 列表行与字段行之间｜mid 1px `#BFB39B` 区块内分隔、Turn 之间、表格竖线｜thick 2px `#221C16` 大区之间（页头/主体/页脚）｜spine 3px `#8C4A1C` 激活左脊（导航项、Bot 卡、Turn 头）｜双线 1px + 3px 空 + 1px `#BFB39B` 单据表头下沿，仿签派单。

**阅读节奏**：段落间距 12px，不加空行不加边框；单据字段行上下 8px、标签列固定 96px、标签与值距 12px、行间 1px hair；区块间距 32px，大区 48px + 2px 粗线。body 行高统一 1.65——这是「读文件」不是「扫表格」。

## 5. 组件规格

**5.1 Bot 卡片（同事，不是机器人）** 148px 高，sheet 底，6px 圆角，1px hair 框，左脊 3px。五行：① **名章** 40×40（sheet 底 + 1px ink-1 框 + 衬线首字母 20px——方形印章，不用圆头像、不用机器人图标）② 姓名 19px serif 600 + 右侧印章 ③ 人格摘要 13px sans ink-3 单行截断 ④ 运行时徽标（描边）+ 协议 + 模式 13px sans ⑤ `worktree` sans + 路径 mono 12px 中段省略，右端 `待批 2` 用 mark 色。状态：default 左脊透明｜hover 底 alt + 左脊 3px primary（**不位移不放大**）｜focus 2px primary 外描边 offset 2｜active 底 sunk｜disabled（运行时不可用）整卡 60% 不透明 + 顶部 1px 虚线横幅，**字段不删**。悬停才出现次操作（详情/派任务/更多），右下 13px sans。

**5.2 Turn 头与 Session 分隔条** Turn 头 36px 高，上边 1px hair；左名章 24px｜中 Bot 名 15px serif 600｜右运行时 12px sans ink-3（`·` 分隔模式）；滚动吸顶时底 paper + 下 1px mid。Session **仅变化时**在下方插一条横贯带子：整行 alt 底、上下 1px mid、居中 13px sans ink-2，文案 `新 Session · 已重建上下文（人格 + 记忆 + 最近 20 条）`——是带子不是卡片。

**5.3 事件折叠块** 30px 高，无边框，仅上方 1px hair。左符号列固定 20px（mono 13px，色按 §2）｜正文 13px sans｜右端时间 12px mono ink-3。hover 整行 alt；展开内容 sunk 底、mono 13px、左右 16px、上边 1px hair。focus：整行 2px primary 内描边。

**5.4 权限卡片（单据，核心）**

```
│ 权限请求                    № P-0031 │  待签    │  serif 19 + mono 编号 + 印章
├──────────────────────────────────────┴──────────┤  ← 双线
│ 动作   写文件                                    │
│ 目标   /etc/hosts          mono，超长换行        │
│ 来源   研究助手 · Gemini CLI · 本会话            │
│ 时限   87s                 mono 倒计时           │
├─────────────────────────────────────────────────┤
│ [批准一次][拒绝][记住本会话][记住本 Bot]  签署：你│  ← 签章区
└─────────────────────────────────────────────────┘
```
sheet 底，1px ink-1 外框，6px 圆角。阻断时左脊 3px mark，sticky 在输入框上方 12px。**三态**：阻断（倒计时、输入框锁定、按钮为唯一焦点区）｜挂起（无倒计时，时限行改「已挂起 1h 20m · 最长 24h」，印章「挂起中」）｜失效（整卡 sunk 底，按钮全禁，印章「已失效」+ 一句原因）。已决后折叠为一行审计行 `已批准 · 你 · 14:32 · № P-0031`，可展开回看。

**5.5 消息块** 用户消息：左脊 3px primary，底 primary-soft，6px 圆角，右上小字 `你 · 14:31`。**Bot 消息不加底不加框**，直接排在 Turn 头下方（正文即内容，避免气泡聊天）。引用块：左侧 2px mid 竖线 + 缩进 16px + 13px sans ink-2。

**5.6 输入区** 表单形态非气泡：sheet 底，1px mid 框，6px 圆角，内边距 12/16。上方 1px hair「收件人行」`致 研究助手 · Gemini CLI · local ~/project`（13px sans + mono 路径）。底部工具行 `@` / `转任务` / `设为定时` 左对齐，主按钮右端。锁定态：外框转 2px mark，占位文字 `等待你批准，无法继续发送`。

**5.7 按钮**（13px sans 500，动词开头，不用全大写）
| 类型 | default | hover | active | disabled | focus |
|---|---|---|---|---|---|
| 主 | 底 `#8C4A1C` / 字 `#FBF8F0` / 无框 / 高 34 / 圆角 3 / 内边距 16 | 底 `#74390F` | 同 hover + `inset 0 1px 2px` | 底 `#E2DCCB` / 字 `#857963` | 2px `#8C4A1C` 外描边 offset 2 |

| 文字 | 无底 / 字 ink-2 / 下划 1px hair | 下划 ink-1 | 字 ink-1 | 字 ink-4 | 同上 |

**5.8 印章式状态标记** 内边距 3px 8px，2px 圆角，11.5px / 500 / 字距 +0.04em，形状见 §2 印章色板。**必须带文字**，任何状态都不靠颜色独立传意。

**5.9 能力徽标** 1px ink-3 描边，3px 圆角，内边距 2px 6px，micro。`支持`（ink-1 字 + ink-1 框）｜`不支持`（ink-3 + hair 框，**不加删除线**）｜`未知`（ink-3 + **虚线**框）。未知绝不画成灰块或假按钮。

**5.10 Assignment 单据卡** 表头：标题 serif 19px + 编号 mono 右上 + 印章。字段行：指派 / 交付物 / 位置 / 耗时 / 用量。完成追加「报告摘要」：上 1px mid，3 行 13px sans，底行 `改动 4 个文件 · 12.4k in / 3.1k out` mono。状态推进只换印章与字段值，**结构不跳动**。

**5.11 表格（用量 / 审计）** 直角。表头底 alt + 下 1px ink-1，单元格上下 10px 左右 12px，行间 1px hair，无竖线（用量表保留一条 Bot/运行时分组竖线）。数字右对齐 + `tabular-nums`。悬停行 alt。

**5.12 空态** 居中宽 480px：16px serif 一句（`还没有会话。从任一 Bot 的卡片开始私聊。`）+ 13px sans 两行 + 一个主按钮。**不加插图不加图标**。筛选无结果用另一套：13px sans 一行 + 文字按钮「清除筛选」。

**5.13 导航项** 36px 高，直角，左脊 3px（激活 primary，否则透明），内边距 0 12px，13px sans。激活：字 ink-1 600 + 底 alt；hover 底 alt；focus 内描边 2px primary。分组间 1px hair。底部计数用 mono 12px ink-3，待批用 mark 色。

**5.14 轮次栅栏（群聊）** 整行居中，上下 1px hair，13px serif ink-3：`— 本轮结束 · 3 个 Bot · 4,120 token —`。群聊可读性的骨架。

## 6. 关键页面

**`/bots`（同事名录）**：页头 display 34px serif「Bot 名录」+ 右侧汇总 `6 个 Bot · 3 种运行时 · 2 个执行中 · 3 条待批`（13px sans，数字 mono），头下 2px 粗线。筛选条一行无框，仅底 1px hair，选项为文字 chip（选中加 2px primary 下划线）。网格 gap 16px。每卡是**人员档案卡**：名章 + 衬线姓名是唯一强视觉，其余全为 13px 元信息；卡间不投影不浮动。

## 7. 动效（温和）
| 动效 | 时长 | 缓动 | 说明 |
|---|---|---|---|
| 流式光标 | 1000ms 循环 | ease-in-out 交替 | 2px × 1.1em mark 竖块，opacity 1 ↔ .2 |
| 事件出现 | 140ms | `cubic-bezier(.2,.7,.3,1)` | opacity 0→1 + translateY 4px→0，不逐条排队 |
| 权限卡片进入 | 240ms | `cubic-bezier(.2,.8,.25,1)` | translateY −8px→0 + opacity；表头双线 320ms 内从左画到右 |
| 印章落下 | 260ms | `cubic-bezier(.3,1.4,.5,1)` | scale 1.18→1 + opacity，一次性轻过冲模拟压章，之后不再动 |

`prefers-reduced-motion: reduce`：光标改静态实心块；事件与卡片进入 0ms 直显；印章不缩放，仅 opacity 0→1（80ms）。

## 8. 与 UX 五原则的对应
1. **Bot 是主角**：全站大字号衬线只给 Bot 名与页面标题；运行时永远是 13px 描边徽标，永不做成标题或图标；名章是方形印章不是机器人头像。
2. **能力可见非缺失**：能力徽标三值都有形态（支持 / 不支持 / 未知），未知是虚线不是灰块；未声明事件根本不渲染，不留空行灰条。
3. **治理在主流程内**：权限请求是一张可签单据，编号与印章让它像流程的一部分而非弹窗；已决后折叠成审计行仍留在流里。
4. **一次只展开一层**：折叠块只用一条 1px hair 分隔、30px 高，展开才出现 sunk 底；层级靠字号与底色区分，不靠嵌套边框。
5. **缺席要可解释**：所有「没发生」都是 13px sans ink-3 一行说明，就在本该有内容的位置（如 Turn 尾 `本轮无 Bot 发言 · 主持人未返回名单`），不留空白。

## 9. 局限与风险
| 风险 | 表现 | 缓解 |
